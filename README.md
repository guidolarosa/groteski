# groteski

## Purrflix

Netflix-style frontend for a cat-content streaming site. Plain HTML, CSS, and JavaScript — no build step. Mood rows cover Sleeping, Playtime, Relax, Rainy Day, Bird Watching, and Night Hunt. Each title opens a player with an animated canvas scene, and the signup flow is a $1/month demo (nothing is charged).

### Run it

From the repository root:

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

A title can be opened directly with a hash, for example [http://localhost:8080/#play=rainy-0](http://localhost:8080/#play=rainy-0).
